ROYAL GALLERY SETUP
1. Copy this entire folder to C:\xampp\htdocs\Royal_Gallery
2. Visit http://localhost/Royal_Gallery/
3. Put your video at media/royal-video.mp4
4. Put JPG photos into media/album1, media/album2 and media/album3, named photo1.jpg, photo2.jpg, photo3.jpg.
5. To add more images or change album names, edit the albums array near the bottom of index.html.
No database required. This is a standalone gallery website.
